# Venture Forge website concepts

Five homepage concepts for a single Venture Forge site covering Austin, Dallas–Fort Worth, Birmingham, Silicon Valley and Franklin.

| Route | Style reference |
| --- | --- |
| `/a` | Founders Club |
| `/b` | Soho House |
| `/c` | Joby Aviation |
| `/d` | Partiful |
| `/e` | Telescope |

All copy and asset paths live in `lib/content.ts`. Each concept is self-contained in `app/<letter>/`.

```
npm install
npm run dev
```
